## ☁️ ITMO-544: Cloud Computing Technologies for Fall 2026

A hands-on graduate course at the **Illinois Institute of Technology** focused on building resilient, auto-scaling applications. The curriculum bridges the gap between software development and cloud infrastructure engineering.

### 📋 Course Overview
The curriculum focuses on designing, analyzing, and deploying collaborative and non-collaborative applications hosted on dynamically scaled virtual infrastructure. Every cloud deployment is evaluated across six real-world engineering dimensions:
* **Cost Optimization**
* **Device & Location Independence**
* **Elastic Scalability**
* **System Reliability**
* **Security Boundaries**
* **Environmental Sustainability**

### 🚀 Key Takeaways & Project
* **Hybrid Architecture:** Deep dive into both public commercial vendors (like AWS) and local private cloud environments.
* **The Integration Project:** A major, group-based engineering project where you apply course concepts to build and launch a live, auto-scaling cloud application.
* **DevOps Foundation:** Moves past basic setup to prepare you for production-grade infrastructure and advanced tracks.
